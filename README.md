# MLBB Web Presentation

Presentasi berbasis HTML, CSS, dan JavaScript untuk materi **DataSet Mobile Legends Bang Bang E-Sport Heroes Stats**.

## Cara menjalankan
1. Ekstrak file ZIP.
2. Buka folder `MLBB_Web_Presentation`.
3. Klik dua kali `index.html` atau buka lewat VS Code + Live Server.
4. Pastikan koneksi internet tersedia untuk memuat Chart.js dan Google Fonts.

## Kontrol presentasi
- `→` / `Space` / `Page Down`: slide berikutnya
- `←` / `Page Up`: slide sebelumnya
- `Home`: slide pertama
- `End`: slide terakhir
- `Esc`: tutup menu overview
- Tombol `OVERVIEW`: pilih slide langsung
- Tombol `⛶`: fullscreen
- Di HP: swipe kiri/kanan

## File
- `index.html` — struktur slide dan konten
- `style.css` — desain, layout responsif, animasi, dan transisi
- `script.js` — navigasi, chart, counter, dan interaksi

Catatan: Grafik memakai Chart.js dari CDN, sehingga koneksi internet diperlukan ketika pertama kali membuka presentasi.
